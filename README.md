# Kata 1 - Ingeniería del Software 2

Microproyecto en Java con IntelliJ para practicar el IDE (shortcuts, debugger,
refactorización) y el flujo de Git y GitHub.

Tiene una clase `Person` (un record con nombre y fecha de nacimiento) que
calcula la edad, y un `Main` que crea una persona y muestra su edad por consola.

La rama `master` tiene la versión final y `develop` es la rama de trabajo.
Hice la kata tres veces en días distintos: la primera en `master` (30/09), la
segunda en `develop-2` (12/10) y la tercera en `develop-3` (13/10), que es la
versión final.
