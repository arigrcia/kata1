# Kata 1 - Ingeniería del Software 2

## Qué hace

Hay una clase `Person` que guarda un nombre y una fecha de nacimiento, y
calcula la edad. `Main` crea una persona de ejemplo y muestra su edad por
consola.

## Flujo de Git

Trabajé en `develop` y fui integrando a `master`. Cada repetición de la kata
la hice en su propia rama: `repeticion-1`, `repeticion-2`, `repeticion-3`.

Commits principales: gitignore, clase Person, clase Main, ajuste del groupId.
